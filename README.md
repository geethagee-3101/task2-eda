# Task 2: Exploratory Data Analysis (EDA)

## Description
This project explores the Iris dataset using Python to identify patterns, relationships, and potential outliers.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Analysis Performed
- Summary statistics
- Histogram
- Boxplot
- Scatter plot
- Correlation heatmap
- Count plot

## Key Insights
1. Petal length and petal width show a strong positive correlation.
2. Setosa flowers are clearly separated from the other species based on petal measurements.
3. Each species contains 50 samples.

## Conclusion
EDA helped me understand the dataset through statistical summaries and visualizations.
